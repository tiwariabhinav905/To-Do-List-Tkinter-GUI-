# To-Do List

A simple and efficient To-Do List application designed to help users organize their daily tasks and improve productivity.

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* Clean and easy-to-use interface
* Fast and lightweight

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

This project was built to practice front-end web development concepts, including DOM manipulation, event handling, and responsive UI design, while creating a practical application for everyday task management.

## Future Improvements

* Task categories
* Due dates and reminders
* Local storage/database support
* Dark mode
* Search and filter functionality
* User authentication
